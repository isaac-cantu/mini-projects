# 🧩 Mini Projects Repository

This repository contains a collection of **small programming projects** developed on a **weekly basis**. Each mini-project focuses on exploring a specific concept, tool, algorithm, or technology using different programming languages.

The main goal of this repository is **continuous learning through hands-on practice**, improving problem-solving skills, and building a diverse technical portfolio.

---

## Objectives

* Practice multiple programming languages
* Explore new tools, libraries, and frameworks
* Reinforce fundamental and advanced concepts
* Maintain consistent weekly coding habits
* Build a structured and evolving portfolio

---

## Project Frequency

* **One mini-project per week** (on average)
* Each project is self-contained and focused
* Projects may vary in complexity depending on the topic

---

## Topics Covered

Depending on the week, projects may include:

* Algorithms and data structures
* Robotics and control systems
* Data analysis and visualization
* Machine learning and AI
* Computer vision
* Simulation and modeling
* Automation scripts and tools
* Mini videogames
* Etc
